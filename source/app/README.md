# ImaKuite!Inspector! (Expo / React Native)

今日のあなたの投稿が、未来のあなたの「食べたい」を支えます。
今日からあなたも、インスペクター。

## 起動

```bash
npm install
npm run web      # Web（先行公開用）
npm start        # 実機は Expo Go で QR を読む
```

## 現在できること（第1段階・端末内保存のみ）

- 調査官登録（ニックネーム・好きな食べ物・国籍・年代・性別・アレルギー。氏名や連絡先は集めない）
- 入店打刻（現在地 → Open-Meteo で天気・気温・気圧を自動記録）
- 調査報告書（入力項目タブで入力項目を増やすほどポイントが増える）
- 店をさがす／店の詳細（評価人数表示・ランクに応じた黒塗り解除）
- ルーレット（好み／未訪問／高評価／ランダム）＋事後評価
- マイページ（階級・信頼スコア・投稿の訂正履歴・ポイント台帳）

## まだ無いもの（`../api-spec.md` `../schema.sql` を参照）

- サーバ連携（heteml の PHP + MySQL）、パスキー認証
- 店舗マスタの OpenStreetMap 取り込み（現在はサンプル8店）
- 他の投稿者のデータ（現在はサンプル表示）、同時投稿人数の実測
- 写真の EXIF 除去・顔ぼかし、アカウント削除
