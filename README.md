# ImaKuite!Inspector!（イマクイテ・インスペクター）

覆面調査官として食レポを投稿するとポイントが貯まり、蓄積データから味覚が合う店をマッチングするアプリの構想です。

> 今日のあなたの投稿が、未来のあなたの「食べたい」を支えます。
> 今日からあなたも、インスペクター。

## このリポジトリについて

- **[`index.html`](index.html)** — 動く試作機（プロトタイプ）。投稿・ポイント・ランク進捗・特命ルーレットなど主要な操作感を実際に触って確認できます。
- **[`lp.html`](lp.html)** — サービス紹介のランディングページ。

第1期の調査区域は岡山市北区・中心部を予定しています。

## 試作機の位置づけ・制限事項

これは**設計初期段階の使い勝手検証用プロトタイプ**です。実際のリリース版とは以下の点が異なります。

- **サーバーを持たない構成です。** すべてのデータはブラウザの `localStorage` にのみ保存され、他の利用者とは共有されません。ブラウザのデータを消去すると記録も消えます。
- 店舗データ・評価データはすべてダミーです。
- 認証・写真アップロード・実際のポイント精算などバックエンドを要する機能は未実装です。
- 実際のリリース版はネイティブアプリ（iOS/Android）として、パスキー認証・heteml＋外部ストレージ構成で開発予定です。個人情報（氏名・住所・電話番号）を保持しない設計を予定しています。

## 触ってみる

`index.html` をブラウザで開くだけで動作します（ビルドや依存関係のインストールは不要です）。GitHub Pagesが有効な場合はこのリポジトリの Pages URL からも確認できます。
